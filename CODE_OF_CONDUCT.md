# Código de Conduta

Queremos uma comunidade respeitosa e acolhedora para todas as pessoas, independentemente de idade, gênero, origem, experiência ou nível de conhecimento.

## Esperamos

- Respeito e gentileza nas conversas.
- Críticas construtivas e abertura para aprender.
- Foco no que é melhor para o projeto e para quem joga.

## Não toleramos

- Ofensas, assédio, discriminação ou ataques pessoais.
- Publicar informações privadas de outras pessoas, inclusive tokens de acesso e dados de jogadores.

## Aplicação

Comportamentos inadequados podem levar à remoção de comentários, issues ou PRs e ao bloqueio de quem os praticou. Para denunciar, abra uma issue ou entre em contato com o mantenedor pelo perfil [@stumdev](https://github.com/stumdev).
